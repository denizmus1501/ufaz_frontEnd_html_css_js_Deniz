Documentation of the HTML elements used in my CV

This part documents every HTML element and attribute used in this CV. For each element I followed the same method of working:

  1. document the element and its attributes (MDN Web Docs and the W3C specification);
  2. understand how to use it (context of use);
  3. identify its semantics;
  4. try the examples and display them in a browser;
  5. apply it to the web document.

The page contains only semantic content elements. The neutral elements (div, span), the sectioning elements (header, footer, article, section, aside, nav) and all obsolete or deprecated elements and attributes are deliberately not used. CSS is limited to text formatting, web fonts, lists, links, boxes and tables, in the style element of the head. There is no positioning and no layout styling.

Document structure and header tags

Elements of the initial structure of the document
Element and examplePurpose and semanticsAttributesUse in the CV
<!DOCTYPE html> Declaration, not an element. It tells the browser the document is HTML5, so it renders in standards mode instead of quirks mode. None. First line of the page.
<html lang="en"> The single root element; every other element is nested inside it. lang: language of the content, used by screen readers, translators and search engines. Root of the page.
<head> Metadata of the document (encoding, title, description…). Its content is not displayed. None. Contains five meta elements, the title, the link elements and the style element.
<meta charset="UTF-8"> Defines the character encoding. UTF-8 can represent every character, so ə, ş, é, Cyrillic, Korean and symbols such as ℝ are displayed correctly. It comes first in the head because the browser must know the encoding before reading the rest of the file. charset. First line of the head.
<meta name="viewport" content="width=device-width, initial-scale=1.0"> Without it, a phone lays the page out about 980 pixels wide and zooms out, so the text is tiny. width=device-width uses the real screen width and initial-scale=1.0 sets the zoom to 100 %. It is the basis of responsive design. name, content. Makes the CV readable on a phone.
<meta name="description" content="…"> Short summary of the page, often shown by search engines under the page title. name, content. Summary of my CV.
<meta name="keywords" content="…"> Comma-separated keywords describing the content of the page. name, content. Keywords about my studies and skills.
<meta name="author" content="…"> Name of the author of the document. name, content. My name.
<title> Title of the document, shown in the browser tab, in bookmarks and in search results. None. "Deniz Mustafayeva | Curriculum Vitae".
<link rel="stylesheet" href="https://fonts.googleapis.com/…"> Empty element that links an external resource to the document. With rel="stylesheet" it loads a CSS file, here the web fonts; with rel="preconnect" it opens an early connection to a server. rel: relationship with the resource. href: address of the resource. crossorigin: needed for the font files. Loads the web fonts (Merriweather, Source Sans 3 and Fira Code) from Google Fonts.
<style> Contains the CSS rules of the document. It is placed in the head and its content is not displayed. None needed in HTML5 (type="text/css" is optional). All the text formatting, list, link, box and table styles of the CV.
<body> Contains everything rendered in the browser window. None. All the visible content of the CV.

Links and images

Links, anchors and images
Element and examplePurpose and semanticsAttributesUse in the CV
<a href="#skills"> Hypertext link. An absolute link points to another site, a relative link to a file of the same site, and a link starting with # jumps to the element with that id. The tel: scheme opens the phone dialer. href: target. target="_blank": new tab. rel="noopener noreferrer": security with new tabs. title: tooltip. hreflang: language of the linked page. Menus, telephone, GitHub, LinkedIn, UFAZ website and "Back to the top". The email is plain text, because a mailto: link is easily collected by spam bots.
<img> Empty element that embeds an image. The alt text replaces it for screen readers or when it cannot load. src, alt, width and height (reserve the space and avoid layout jumps), title, id, loading="eager" (load immediately), decoding="async" (decode without blocking the page). The illustration under my name.
